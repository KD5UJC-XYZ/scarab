UTXOW's `validateMetadata` and `validateScriptsWellFormed` run on it, the auxiliary data validated through `EraTxAuxData#validateTxAuxData` and each script through `isValidScript` over the cache; on the Conway corpus, crafted malformed scripts and the reference's recorded refusal their verdicts are the existing checks', and where both reach the scripts and the decoder gives no verdict they name the same first script, in the order the scripts arrived. `validateMetadata` reads the scripts only where the auxiliary data and its hash are both present, the reference's order, so auxiliary data without its hash is its `MissingTxBodyMetadataHash` where the existing check, which reads the scripts first, reports the decoder's missing verdict.
