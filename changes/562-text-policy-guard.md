### Added (scripts, #562)

- `scripts/check_text_policy.py` refuses an unreviewed `Value.Text` mention in `ledger/src/main` outside `CborRead`, which holds the Shelley-through-Conway definite-string rule, naming the file and the line. It blanks comments and string literals before matching. Explicit file exceptions cover the metadata readers (`AuxiliaryScripts` and `DijkstraWitnesses`), value inspection (`Semantic` and `ForgeProblems`), the genesis JSON encoder (`GenesisPoolFields`) and Dijkstra's version-12 text reader (`V12`), which permits chunked text as the newer pinned reference does. Every exception carries a reason and a live mention. The guard runs in preflight and CI; executable interpolation, wildcard imports and line continuations remain outside its coverage under #562.
- `CborRead.indefinite` is the text rule's head test in one place: the value and whether it was chunked. `CborRead.text` reads through it, and a reader whose refusals are its own takes the flag instead of matching `Value.Text` again — the relay name reader now refuses a chunked `DnsName` with `PoolRelayError.IndefiniteDnsName` through it (#435).
