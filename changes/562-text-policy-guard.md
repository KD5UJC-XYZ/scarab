### Added (scripts, #562)

- `scripts/check_text_policy.py` refuses a `Value.Text` match in `ledger/src/main` outside `CborRead`, the reader that holds the definite-string rule, naming the file and the line. It blanks comments and string literals before matching, so documentation that quotes the constructor does not trip it. `AuxiliaryScripts` (the metadata reader, which reads a chunked text as the joined text), `Semantic` (which names the joined value of a value, not of a block-body field) and `ForgeProblems` (which names the shape of a map key and discards it) are allowlisted with the reason the rule does not apply, and an entry without a reason fails the check. It runs in preflight and in the `scripts` CI job.
- `CborRead.indefinite` is the text rule's head test in one place: the value and whether it was chunked. `CborRead.text` reads through it, and a reader whose refusals are its own takes the flag instead of matching `Value.Text` again — the relay name reader now refuses a chunked `DnsName` with `PoolRelayError.IndefiniteDnsName` through it (#435).
