### Fixed (scripts, #694)

- `scripts/cleanup.py --stale-days` could never find a worktree stale: its own `git status` rewrote the index whose time it then read as the worktree's last activity. Listing no longer refreshes the index. Activity is the latest change to HEAD, its reflog, the index, the worktree's link files or a tracked file (modification or change time), so an edit undone in the working tree, a restore that keeps old file times and a moved worktree all count; a worktree without a HEAD reflog, whose commits and resets leave no trace of their time, counts as of unknown activity and is kept.
