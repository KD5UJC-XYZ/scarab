### Changed (ledger, #488)

- A chain whose first era is Shelley-based (the devnet, Preview and other test networks that schedule their hard forks at epoch 0) starts from the state the reference makes: the Byron genesis UTxO translated to the first era, then that era's genesis injection. The start no longer predicts a protocol-parameter update or precomputes the first epoch's reward update, the injected staking keys before Conway get the pointers the reference gives them, and the Alonzo genesis `extraConfig.costModels` override only the current parameters, from Alonzo. A chain that starts in Byron hands over the translated genesis parameters without those injected cost models; the supplied injection is still parsed and validated.
- An era-skipping start on a network whose Shelley genesis names `Mainnet` is refused, as the reference refuses its injection, and so is an injection given both in `extraConfig` and in the legacy field. This node also refuses an injection read from a file (`InjectionFromFile`), which the reference reads (#499).
- The `legacy` module (the frozen flat state and its conversion) is removed.
