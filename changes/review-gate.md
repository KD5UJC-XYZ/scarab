### Changed (every pull request gets an independent review)

- **Every pull request gets an independent review of its final diff before it is marked ready**: for agent work, a
  read-only Codex review, posted on the pull request and linked from its "Independent review" section
  (CONTRIBUTING.md, "Independent review"; the recipe is `docs/playbooks/review-a-change.md`). The pull request
  policy check refuses a pull request that is not a draft without that section and a link in it.
