### Added (era types, #85)

- Conway's governance proposals and votes are typed by era (`GovAction[E]`, `ProposalProcedure[E]`, `VotingProcedures[E]`), as the reference's `ProposalProcedure era` is. A proposal's action is at the reference's types: a parameter change carries the era's update (`PParamsUpdate[Conway]`), each parent is the id of its own purpose (`GovPurposeId`), and the committee, epochs, threshold, version and script hashes are typed. Conway's body and its proposing purpose carry them. Every recorded Conway proposal, of each of the seven actions, reads with the fields the existing decoder reads, and what the typed proposal would refuse the existing decoder refuses first.
- The first functions of Conway's GOV rule run on the era types (`ledger/era/rules/Gov.scala`): the bootstrap-phase proposal check, an update's well-formedness, the guardrails script and the unelected committee voters, each the reference's function generic in its era. Their failures equal the existing rule's on every recorded Conway refusal and on crafted cases. The node still judges with the existing rule, so behaviour does not change.
