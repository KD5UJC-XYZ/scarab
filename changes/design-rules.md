### Changed (contributor rules)

- The rules the code follows now have one home, [docs/design-rules.md](https://github.com/KD5UJC-XYZ/scarab/blob/main/docs/design-rules.md): each rule has a stable ID, its scope (main, tools, tests), its exceptions and how a kept site is marked, what enforces it and why. `AGENTS.md` and `CONTRIBUTING.md` link it instead of restating the rules, and a pull request's "Deviations from the reference" table names each difference's class (Improvement or Deviation) with its approval.
