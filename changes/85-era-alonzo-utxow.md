### Added (era types, #85)

- Three predicates of the UTXOW rule run on the era types (`ledger/era/rules`), each the reference's function generic in its era over its classes: the key-witness signatures (`validateVerifiedWits`), the script witnesses beside the reference scripts (`babbageMissingScripts`) and the script integrity hash (`checkScriptIntegrityHash`), with the script integrity it is over (`ScriptIntegrity`, `mkScriptIntegrity`, the language views). Their verdicts equal the existing rule's on every recorded Conway refusal and transaction, and on crafted cases for what the corpus never refuses; the integrity's bytes equal the existing rule's for every set of languages. The node still judges with the existing rule, so this changes no behaviour. As the reference does, the typed signature check lists the keys of failing witnesses in the witness set's order, where the existing rule lists them as they arrived.
