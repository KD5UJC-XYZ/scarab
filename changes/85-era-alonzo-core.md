### Added (era types, #85)

- Alonzo has era types of its own: its era tag, its output (`AlonzoTxOut`), read from a body's output and written as the reference writes it, with its least coin through the cost per UTxO word, its scripts (`AlonzoScript`, native or Plutus V1), and its protocol parameters (`AlonzoPParams`), mirroring the reference's higher-kinded record, with Alonzo's instances of the parameter classes and classes of their own for the parameters only some eras have (the cost per UTxO word; the decentralisation and the extra entropy). Babbage's upgrade of Alonzo's parameters and its downgrade to them come as Babbage's functions, and Alonzo's update proposals read with the bytes of each value, the form the node stores a proposal in. Every recorded Alonzo output and parameter record reads and writes as it does now, and the reference's own Alonzo UTxO answers are written byte for byte. Nothing in the node uses these types yet, so behaviour and the persisted format do not change.
