### Added (ledger, #826)

- SNAP rotates the Leios layout's snapshots as the Leios testnet's build does before Dijkstra: the new mark records the epoch the chain enters with a committee size and key age of zero, and the old mark's Leios committee is seated in the set position. The rotation agrees byte for byte with the native `mkMarkSnapShot`, `mkSetSnapShot` and `mkGoSnapShot` on the recorded cases. A committee SNAP cannot select stops the node rather than refusing the block: a state the reference cannot hold (`ChainError.LeiosCommittee`), or a failure of the BLS library (a provider defect). The key age Dijkstra's SNAP derives from the KES parameters (`EpochInterval.ofKes`) agrees with the native `maxKeyAgeEpochs`, its word wraps included; Dijkstra's SNAP itself is not implemented yet (#826).
