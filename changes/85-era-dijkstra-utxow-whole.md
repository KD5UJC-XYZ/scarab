### Added (era types, #85)

- Dijkstra's UTXOW, UTXO and UTXOS rules run on the era types, as the Leios testnet's build (cardano-ledger 9df9f98c) has them: Dijkstra's own UTXOW and UTXO, with the guards' checks, the batch's collateral, the value conserved over the batch and, for scripts up to Plutus V3, over the top level alone, and Conway's UTXOS. Their failures are the reference's own types with its injections. Where the reference's injections call a case impossible, the shared checks declare the cases they report, so the injections cover exactly the cases the rules can reach and the impossible ones do not compile. On each of the reference's 17 UTXOW cases the failures encode to the reference's refusal byte for byte and equal the existing rule's. The rules accept every transaction a ranking block of the public Leios testnet's chain holds without sub-transactions, with every Plutus script passing. The node still judges with the existing rules, so nothing changes in behaviour.
