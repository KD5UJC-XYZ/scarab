### Added (code map and issue digest, #400)

- `docs/codemap.md` is generated by `scripts/render_codemap.py` from `docs/data/codemap.json` and the `dependsOn` clauses of `build.sbt`: the module graph, then per Scala package its responsibility, entry-point symbols, covering suites and owning ADRs or designs. CI runs it with `--check`, which also fails on a missing symbol, suite or document, an unmapped package, or an entry for a package that is gone.
- `scripts/status.py` prints a one-line-per-issue digest of the open issues grouped by area (priority, status, roadmap id); it reads `gh issue list` or a saved file (`--from`) and writes no tracked output.
