### Added (era types, #85)

- The reference's state classes for the accounts and the certificate state (`EraAccounts`, `ConwayEraAccounts`, `EraCertState`, `ConwayEraCertState`) have Conway's instances over the state the node keeps, with the reference's functions over them: account lookups and registration, the deposits the state owes (`obligationCertState`), the withdrawals that do not drain their accounts, and the moves of a pool's and a DRep's delegators.
- Conway's certificate rules run on the era types (`ledger/era/rules`): CERTS, CERT, DELEG, GOVCERT and Shelley's POOL, each the reference's transition generic in its era over those classes. From the same state they judge every recorded Conway refusal, at its own protocol version and at 9, 10 and 11, as the existing rules do: the same failures in the same order, or the same certificate state. Certificates crafted against a recorded state reach every failure the rules record. The node still judges with the existing rules, so behaviour does not change.
