### Added (peer sharing governor, #138)

- The governor discovers peers through negotiated PeerSharing and inbound connections with the reference's
  activation, retry, two-request and two-stage batch policies. Late results respect the remaining discovery
  objective; configured advertisement flags survive duplicate discoveries.
- Relays enable sharing by default, producers disable it by default, and an explicit `PeerSharing` Boolean
  wins. The server publishes only advertised, successfully connected peers without failures and applies
  its existing 823-second salt and ten-peer cap. IPv4/IPv6 socket conversion follows the reference wire.
- Requests use the caller's error capability, own their fiber scope, and drain bounded wire replies after
  logical discovery timeout. Defects stop the node without peer blame.
- Deterministic hour-long governor simulations and a private two-way Haskell relay discovery scenario
  (`devnet.py peer-sharing`) cover scheduling, discovery use, advertisement and actual reference replies.
