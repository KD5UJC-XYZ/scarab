### Added (era types, #85)

- Conway's UTXOW rule runs whole on the era types: the witness, script, datum, redeemer, metadata and script-integrity checks, the failing native scripts, then the UTXO rule as its sub-rule. Its failures and events are the reference's own types for each era, with the reference's injections between them, and native scripts are evaluated on the era types. On the Conway transactions the reference node was given, on every Conway case of the refusal corpora and on the recorded verdicts on a certificate's redeemer index, under each build and validation policy, it gives the existing rule's failures in the same order and leaves the same state; where the reference refused a transaction for UTXOW and UTXO alone, its failures encode to the reference's refusal byte for byte. The node still judges with the existing rule, so nothing changes in behaviour.
