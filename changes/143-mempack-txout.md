### Added (the MemPack `TxOut` codec, stage S1 of Step D, #143, #140)
- **`TxOutMemPack` encodes and decodes the ledger's `TxOut` in the `mempack` binary format that `cardano-ledger` writes into the `tables` file of a LedgerDB snapshot**, for the Shelley to Conway eras (all six constructors: compact, datum hash, the "Addr28" forms of a base address with ada only, inline datum, reference script of every kind; the multi-asset value in the ledger's flat representation). The era is a type parameter (`ShelleyBasedEra[E]`), a constructor the era lacks and a value that has no compact form are typed `MemPack.Failure`s, and a decoded output carries the canonical CBOR as its `raw`. Checked against 95 outputs of a real preprod snapshot written by node 11.1.3, the seven devnet snapshots of `fixtures/haskell-state`, the independent Python decoder, and properties for every era. Nothing the node stores changes; the design, the format and the decision on storing the UTxO in this form are in `docs/design/haskell-snapshots.md`.
