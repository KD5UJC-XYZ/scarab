### Added (conformance)

- `scripts/conformance/run.py` writes Scarab's reports for the scenarios of [node-diversity-conformance](https://pragma-org.github.io/node-diversity-conformance/) (`ledger-rules`, `uplc-conformance`, `uplc-turbo`, `cbor-decoding` per era): it builds the tools in the JDK image, fetches the scenario's pinned inputs (`scripts/conformance/pins.json`) and verifies them, runs the tool with Scarab's own Plutus evaluator, checks the report against the scenario's schema and corpus, and names it `scarab-YYYYMMDD-<scenario>[-<era>].json.gz` beside a provenance file. `scripts/conformance/publish.py` uploads them on demand to the `conformance-reports` pre-release, which is not a Scarab release (a dry run unless `--apply`), and the **Conformance reports** workflow runs both by hand only. `uplc-turbo`, a timing benchmark, runs ad hoc on a quiet machine, never on CI. See `docs/running/conformance.md`.
