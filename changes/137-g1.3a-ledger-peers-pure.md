### Added (peer selection, ledger peers, #137)
- **Pool relays are decoded from the ledger's registered pools** (`PoolRelays`): single host address, single host name and multi host name
  (SRV, kept and marked skipped, design decision D9), with the reference's mapping to ledger relays (IPv4 before IPv6, a name without a port is
  SRV) and a closed error type; checked against the real mainnet registration at slot 4,495,760.
- **Ledger peer and big ledger peer draws** (`LedgerPeerStake`): the stake accumulation, the 90% quota that defines the big ledger peers,
  the square-root and stake weightings, the draw over an explicit generator, the cache lifetimes (30 s while empty, 1847 s otherwise) and the
  rule that picks the peer snapshot or the ledger (`stakeMapWithSlotOverSource`), as `Ouroboros.Network.PeerSelection.LedgerPeers`.
- **The `peerSnapshotFile` is read** (`PeerSnapshot`, versions 1, 2 and 23, exact stakes, typed errors). Nothing uses these yet: the
  governor takes no ledger peers until G1.3b.
