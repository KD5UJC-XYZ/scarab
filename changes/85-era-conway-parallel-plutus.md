### Added (era types, #85)

- Conway's block rules on the era types can evaluate a block's Plutus scripts in the node's bounded parallel workers, under the contract the existing rules follow (ADR 0018): the rules run once, in order, with each transaction's scripts recorded and none evaluated, the workers evaluate them in batches of transactions that do not read or write each other's outputs, and the verdicts land in transaction order. Every result is the serial run's: the same state and counters, the same failures in the same order, the same naming of a script the evaluator gives no verdict on, and the same `--plutus-cases` observations; where a verdict is not the one a transaction's flag announces, the serial rules themselves give the refusal, answered with the scripts' results, so that no script is evaluated twice. The node still applies Conway blocks with the existing rules, so nothing changes in behaviour.
