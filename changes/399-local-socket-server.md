### Changed (node-to-client socket, #399)

- The stale node-to-client socket is removed once the configuration is read, before the topology and the database, with one `unlink` as the reference's `removeStaleLocalSocket`; a directory there is no longer removed by a race. A removal that fails ends the start with one `socketConfigError` line (Error) whose `error` is the reference's text, and exit code 1.
- The socket is bound with the reference's backlog of 8, checked before it accepts, and serves any number of clients. A bind or check that fails, or an accept that fails with anything but `ECONNABORTED` (traced, then retried after 0.5 s), stops the node with a `diffusionErrored` line (Critical) and exit code 1. The socket's file is left in place when the node stops, as the reference leaves it.
- New log events with the reference's names, severities and fields: `createSystemdSocketForSnocketPath`, `createdLocalSocket`, `configuringLocalSocket`, `configuredLocalSocket`, `listeningLocalSocket`, `localSocketUp`, `runLocalServer`, `diffusionErrored`, `socketConfigError` (`Node`), and `serverStarted`, `acceptConnection`, `acceptError`, `serverStopped`, `serverError` (`Net`). `insecureLocalSocketPermissions` and `insecureLocalSocketDirectory` move to the `Node` area and their `path` is the reference's `LocalAddress "<path>"`.
