Test cases of `plutus-conformance/test-cases/uplc/evaluation` from IntersectMBO/plutus tag 1.70.0.0
(commit 507cab8cf6192e5143f12be5b2d3005a2928dc6d, Apache-2.0), unmodified: the `.uplc` programs,
`.uplc.expected` results and `.budget.expected` budgets (the `.flat` encodings are left out).
Used by `PlutusConformanceSuite`.

The six malformed `builtin/parser/value` cases also have Scarab-generated `.flat.cbor.hex` sidecars.
These preserve the entries of the upstream `.uplc` literals in their written order, including
repeated keys, empty token lists and zero quantities. They are CBOR byte strings containing the
original Flat program, generated by `PlutusBoundaryCorpus.malformedValues` with `FlatProgram`.
The text parser otherwise normalises those malformed maps before the Flat decoder sees them.
The original upstream programs, expected results and budgets remain unchanged.
