# LocalStateQuery goldens from a devnet

`genesis/` is the genesis directory of a `cardano-testnet` 11.1.1 cluster of three pools (magic
1082026, `k` = 5, epochs of 500 slots of 0.1 s, started in Conway), exactly as `devnet.py up` copies it.
It holds public data only (genesis delegate and pool key hashes, VRF key hashes, funded addresses).

`golden.json` is what the Haskell `cardano-node` 11.1.3 on that cluster answered at one block (`slot`,
`hash`) to the queries that do not depend on activity: the CBOR of each query and the CBOR of the
answer (the item after the `[4, ...]` of `MsgResult`). `QueryGoldenSuite` rebuilds the ledger state
of the genesis directory and requires the Scala answers to be the same bytes. The cluster had no
transactions beyond genesis when these were recorded, so the protocol parameters, the pools, the
constitution and the other recorded state are those of the genesis files.

Regenerate by starting `devnet.py up`, then running `ntcquery.LocalStateQuery` for the queries named in
`golden.json` against `/work/env/socket/node1/sock` (see `scripts/devnet/ntcqueries.py`) and copying
`/work/env/{shelley,byron,alonzo,conway}-genesis.json` and `configuration.yaml` into `genesis/`.
The `ntc` scenario (docs/running/devnet.md) compares all queries on a live, loaded cluster.

Provenance: generated by `cardano-testnet` 11.1.1 (Apache-2.0) and the unmodified reference node;
no keys of any network, no secrets. Licence of the files: Apache-2.0 (this repository).
