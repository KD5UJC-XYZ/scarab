# 0026. Scala 3.9

- **Status**: Accepted
- **Date**: 2026-10-30
- **Issue**: #649
- **Supersedes**: [ADR 0010](0010-scala-3-3-lts.md)

## Context

[ADR 0010](0010-scala-3-3-lts.md) kept the build on the Scala 3.3 long-term-support line "for now", to be
revisited when a feature or a dependency needed a newer line. The owner decided on 2026-10-30 to move to
Scala 3.9 (#649). Scala 3.9.0 was published on 2026-08-26.

## Decision

**Build with Scala 3.9.0.**

- `-Ysafe-init` becomes `-Wsafe-init`; `-Werror` and the unused-code warnings stay.
- No new warning is silenced wholesale. The one existing `@nowarn` (the `ConstrIndex` override of a
  Scalus parameter, with its guarding test) names 3.9's wording as well.
- Libraries built with older Scala 3 versions keep working unchanged: Scala 3.9 reads their TASTy.

**The era-indexed state needs proofs, not alternative patterns.** Scala 3.9 does not refine a type
parameter through an alternative pattern. In code such as
`era match { case SShelley | SAllegra | SMary | SAlonzo | SBabbage => shelley(c) }`, Scala 3.3 let
`CertState[E]` reduce to `ShelleyCertState`; 3.9 does not, and that refinement was not sound to rely on.
The era tags stay one per era, as in the reference ([ADR 0007](0007-era-indexed-state.md)), and no
grouping tag is added. Instead:

- `ShelleyBasedEra` gives the proof of each family's shape in the era:
  - `shapes`: all four pre-Conway or Conway proofs at once;
  - `cert`, `accounts`, `instantStake`, `gov`, `stashedAvvm`: one family each.
- These are written with one case per era, in `Eras.scala` only. That is the one place that lists
  which eras share a shape.
- Era-generic code uses `EraShape`'s `on`, `update`, `make` and `instance` (built on `=:=`) instead of
  matching on groups of eras. No cast is involved.

**The runtime standard library.** From Scala 3.8 the Scala 3 standard library is its own artifact,
`org.scala-lang:scala-library:3.9.0`. The node no longer carries the Scala 2.13 standard library.

## Consequences

- Artifacts Scarab publishes carry 3.9 TASTy; a library consumer needs Scala 3.9 or later.
- Dated evidence recorded with Scala 3.3.8 stays as it was recorded.
- **Revisit when:** a Scala release changes match-type reduction or GADT refinement again, or a
  dependency needs a newer line.
