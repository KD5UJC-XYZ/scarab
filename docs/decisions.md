# Decisions log

Every decision that shapes the code, with where it is recorded, the invariant it fixes and what reopens it. Checked by `python3 scripts/check_onramp.py`: each ADR in [adr/](adr/README.md) has exactly one row here, and every pointer resolves. A decision that is made or reversed adds a row (an ADR for a design choice; an issue and a roadmap line otherwise).

## Decisions outside an ADR

|---|---|---|---|

| Tagless final with cats-mtl capabilities and closed error types | [ADR 0002](adr/0002-tagless-final-and-cats-mtl.md) | Effects sit behind `F[_]` algebras and cats-mtl capabilities; domain errors are closed ADTs; no string control flow. | None recorded; hot paths are measured before an abstraction is added. |
| Plutus evaluation through Scalus, behind our own interface | [ADR 0003](adr/0003-plutus-through-scalus.md) | Scripts run through the `ScriptEvaluator` algebra; context, phase rules and cost-model handling are ours; deviations are corrected in our wrapper. | Scalus versions move only with conformance and replay evidence; owning the evaluator is the open decision [#43](https://github.com/KD5UJC-XYZ/scarab/issues/43). |
| Build and run only in containers | [ADR 0004](adr/0004-docker-only-build.md) | No host JDK or sbt; each session has its own containers and data directory; run data never enters the checkout. | None recorded. |
| Our own byte-preserving CBOR codec; scodec only for read-once fixed layouts | [ADR 0005](adr/0005-cbor-codec-and-scodec.md) | Anything hashed or signed uses the original bytes; decoding is stack free with typed located errors; per-block paths stay hand-written. | None recorded; measure again before moving a format. |
| Persisted formats are versioned and migrate on open; never a forced replay | [ADR 0006](adr/0006-versioned-formats-migrate-on-open.md) | Every file kind has a version; supported older files migrate atomically on open; unknown or retired versions are refused before mutable stores are acquired. | None recorded; a format change needs a bump, a migration and a previous-version test. |

| Scala 3.3 LTS | [ADR 0010](adr/0010-scala-3-3-lts.md) | The build stays on the 3.3 line with `-Werror` and the unused warnings. | A needed feature or a dependency requires a newer line. |
| Recursion over data from outside is stack safe, in a form the compiler or the library guarantees | [ADR 0011](adr/0011-stack-safety.md) | Recursion over outside data is a library fold, `@tailrec`, `tailRecM` over a typed state or an explicit stack machine; never inside an `Either` for-comprehension. | None recorded. |
| One portable libblst for every x86-64 CPU, shipped where blst-java loads it | [ADR 0012](adr/0012-portable-blst.md) | The BLS12-381 library is the portable build, ahead of blst-java on the class path, and is checked at start-up. | Scalus or blst-java ship a portable build; Dijkstra or Leios needs a newer blst; a platform other than Linux/amd64 is deployed. |
| CBOR documents are an index over the input | [ADR 0013](adr/0013-cbor-documents-are-an-index-over-the-input.md) | A document is an index of two ints per item over the original input; `value` is computed, not cached. | The index of a section no longer fits (several GiB), or the parse in `value` shows in a profile of the per-block path. |
| A typed log: Tell of lines built from typed events, routed by namespace and severity | [ADR 0014](adr/0014-typed-log.md) | Lines are built only from typed events (`Traced`, `EventKind`); a new event case does not compile without its line. | A tool that reads the Haskell node's trace format must read ours, or per-event detail levels are needed. |

| Peer states carry the in-progress transitions, and the governor is a pure decision function under a thin loop | [ADR 0016](adr/0016-peer-states-and-the-governor.md) | A peer is in exactly one state; `PeerSelection.decide` is pure over the state and the time. | Peer sharing or churn needs state the record cannot carry without a second source of truth, or the per-decision views show in a profile. |
| A fiber ends with a value; a typed error does not cross a fiber as an exception | [ADR 0017](adr/0017-fibers-end-with-values.md) | A fiber raises only through a capability it created; a fiber that outlives its caller returns `Either` at its boundary. | None recorded. |
