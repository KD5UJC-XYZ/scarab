# Operational parity (config/topology files, CLI, metrics)

Part of the [compatibility matrix](../compatibility.md); the register entry is `operational-parity` in [compatibility.json](../data/compatibility.json). The three sections below are the cells of the former matrix row, unchanged.

## Status as recorded

partial: `follow --config <config.json> --topology <topology.json>` read the Haskell node's files (genesis file names, `Test<Era>HardForkAtEpoch`, `RequiresNetworkMagic`, `PBftSignatureThreshold`, `LastKnownBlockVersion-*`, `Experimental*`, `ConsensusMode`, `SocketPath`, `DatabasePath`, `MempoolCapacityBytesOverride`; local roots, public roots, bootstrap peers, `useLedgerAfterSlot`); every genesis hash a configuration lists is verified (Byron over canonical JSON, Shelley, Alonzo, Conway, Dijkstra and checkpoints when present); `--genesis-dir` and `--peer` as before; metrics (J3): `GET /metrics` on the query server and `--metrics-listen host:port` export 149 metric definitions (text format 0.0.4), with the Haskell node's `cardano_node_metrics_*` names for what it also measures (chain tip, density, forks, mempool, forging, KES, connections) and `scarab_*`, `jvm_*`, `process_*` for the rest

## Evidence

`ConfigSuite` over the public Preview, preprod and mainnet files (every hash equals its file, including the 1 MB mainnet Byron genesis where present; each of Byron, Shelley, Alonzo and Conway altered gives `GenesisHashMismatch`; Byron hash independent of whitespace; strict reading; the topologies' peers, `useLedgerAfterSlot`, the refusals), `MainArgsSuite`; a Preview run from the official `config.json` and `topology.json` (see the evidence log); a tampered Conway hash stops the node at start with the `ConfigError`; metrics: `MetricsSuite` (a golden text, an independent parser of the format, a property over arbitrary operations and label values that need escaping), `CatalogueSuite`, `EventMetricsSuite`, `CollectorsSuite`, `MetricsServerSuite`, `DocsSuite` (every metric documented with its type and labels), and the devnet `soak` and `pool` scrapes (see the evidence log); the Haskell names were scraped from cardano-node 11.1.3 run as a relay and as a forging pool on the devnet; logging: `LogGoldenSuite` (every event's JSON line byte for byte, every case of every event type), `LogRouterSuite` (thresholds, sampling, rotation, appending, the human format, SLF4J), `LogDocsSuite`, and a Preview run with rotation and per-namespace filtering (evidence log)

## Explicitly unchecked or unconfirmed

full Genesis syncing remains G3; PeerSharing, ledger peers and governor targets are implemented under G1; topology reload, SRV/TTL re-resolution and duplex outbound support are implemented in #142; the legacy `Producers` topology is refused; the configuration is JSON (a YAML file only in JSON syntax); a relative `SocketPath`/`DatabasePath` is relative to the working directory; Dijkstra (`ExperimentalHardForksEnabled`) and checkpoints are not implemented; no CLI parity beyond `follow` (J2); logging (J3a): every line has a namespace and a severity and the `--log-*` flags choose stdout, stderr and a size-rotated file, JSON or human, with per-namespace thresholds and 1-in-N sampling, but `TraceOptions` is ignored (the namespaces are not the Haskell node's), there are no detail levels, no forwarder and the JSON is the node's own shape, not the Haskell `{at, ns, data, sev}`; remaining metric coverage is listed in running.md "Metrics" and roadmap J3e (`served_*`, per-block ledger sizes and selected inbound-governor/replay/transaction-sync series); peer-selection and GSM metrics are exported, with reference-name observations and semantic differences documented; pool monitoring dashboards and alert rules are in ops/monitoring; notification receivers are configured by the operator
